Restaurar backup (substitui dados)

Atenção

Esta operação substitui o banco de dados atual, todas as fotos na pasta de uploads e, se o ZIP incluir, o ficheiro data/.flask_secret. É criado automaticamente um backup de segurança em data/backups/ antes de aplicar o ZIP — guarde cópias externas se o risco for inaceitável.

Para restaurar sem esta página (por exemplo em outro computador), siga o ficheiro LEIA-ME.txt dentro do ZIP (parar servidor, extrair ficheiros, reiniciar).

Com Gunicorn e vários workers (ou várias réplicas), outros processos podem manter ligações antigas ao SQLite. Após restaurar, reinicie o serviço para todos carregarem o novo ficheiro.

Use apenas ZIP gerados pelo menu Backup do sistema ou por scripts/backup_cli.py.
